## 1. intake

![image-20260616161635445](/Users/sr-dfnt/Library/Application Support/typora-user-images/image-20260616161635445.png)

parser가 파일을 `kind/title/content`로 인입 → LLM이 6개 필드 의미 추출 → det dedup → 코드(유사도 후보)+LLM(검증)으로 각 항목에 지지 문서 매핑 → 근거 없는 항목 제거 → `ProblemProfile`. 출력 항목마다 `sources: [문서 title]`이 달려서 검토 ①에서 "이 pain point는 ABC상사 메모 근거"처럼 추적



### input

```json
// INPUT (그래프 진입 / invoke)
{
  "industry": "distribution",
  "documents": [
    {"kind": "brd",        "title": "유통 운영 BRD v1.2", "content": "목표: 납기 준수율 95% ..."},
    {"kind": "sales_note", "title": "ABC상사 미팅 메모",  "content": "성수기 납기 지연 클레임 ..."},
    {"kind": "email",      "title": "물류팀 회신",        "content": "특정 SKU 반복 품절 ..."}
  ],
  "problem": null
}
```

### output

```json
// OUTPUT (state에 기록)
{
  "problem_profile": {
    "goals":       [{"text": "납기 준수율 95% 달성", "sources": ["유통 운영 BRD v1.2"]}],
    "pain_points": [{"text": "성수기 납기 지연 클레임", "sources": ["ABC상사 미팅 메모"]},
                    {"text": "특정 SKU 반복 품절",      "sources": ["물류팀 회신"]},
                    {"text": "공급사 리드타임 변동 큼",  "sources": ["물류팀 회신"]}],
    "kpis":        [{"text": "납기 준수율", "sources": ["유통 운영 BRD v1.2"]},
                    {"text": "부진재고 비중", "sources": ["유통 운영 BRD v1.2"]}],
    "systems":      ["ERP", "WMS"],
    "constraints": [{"text": "PoC 8주 · 거래처 20곳", "sources": ["유통 운영 BRD v1.2"]}],
    "stakeholders": ["물류팀", "영업"]
  },
  "problem": "성수기 납기 지연 클레임 / 특정 SKU 반복 품절"
}
```

## 4. review

```json
// (1) interrupt payload : 그래프 → UI
{
  "stage": "questions",
  "items": [ { "id": "q1", "...": "business_questions 전체" } ],
  "coverage": {"covered": ["납기·리드타임","공급·공급사 리스크"],
               "missing": ["수익·마진","재고 건전성","고객·주문"]}
}

```

```json
// (2) resume : UI → 그래프 (3버튼 중 하나)
{"action": "approve"}
{"action": "edit", "edited_items": [ { "id": "q1", "...": "수정된 질문들" } ]}
{"action": "regenerate", "feedback": "재고 회전 관점 질문도 넣어줘"}
```

```json
// (3) state 기록 : 노드 출력
// 재생성일 때
{"review_questions": {"status": "rejected", "feedback": ["재고 회전 관점 질문도 넣어줘"], "attempts": 1}}
// 승인/수정일 때
{"business_questions": [ "...(edit면 갱신본)" ],
 "review_questions": {"status": "approved", "feedback": [], "attempts": 0}}
```

```json

{
```
