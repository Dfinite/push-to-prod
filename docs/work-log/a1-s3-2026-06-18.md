## 5. available 목록 특이사항

`build_required_sources`의 `available`은 LLD §6 명세 그대로 구현:
- `linked_sources` (예: `orders.o_orderdate`) + `maps_from` 테이블명 (예: `orders`) 동시 포함
- `canned_pack.json`의 `required_sources.available`은 `linked_sources`만 포함하는 참조 형식 — 명세 우선

실제 state에서 `seed.gap.missing[].note`가 full 텍스트를 담으면
`needed`도 `"공급사 리드타임 (TPC-H엔 supplier는 있으나 리드타임 컬럼 없음 → 별도 소스 필요)"` 형식으로 출력됨.

## 6. graph.py 통합 가이드

오케스트레이터가 `graph.py`의 스텁 3개를 실 구현으로 교체할 때:

```python
# graph.py 상단 import 추가
from nodes.workflows import gen_workflows
from nodes.demo import gen_demo
from nodes.export import assemble_export
```

기존 스텁 함수 3개 (`gen_workflows`, `gen_demo`, `assemble_export`) 는 graph.py 에서 **삭제**:

```python
# 삭제 대상 (graph.py 내 스텁)
def gen_workflows(state: DomainPackState) -> Dict[str, Any]:
    return {"workflows": _CANNED["workflows"]}

def gen_demo(state: DomainPackState) -> Dict[str, Any]:
    return {"demo_scenario": _CANNED["demo_scenario"]}

def assemble_export(state: DomainPackState) -> Dict[str, Any]:
    return {
        "required_sources": _CANNED["required_sources"],
        "export": _CANNED["export"],
    }
```

`build_graph()`의 노드 등록은 이름이 동일하므로 **변경 불필요**:
```python
g.add_node("gen_workflows", gen_workflows)  # 그대로
g.add_node("gen_demo", gen_demo)            # 그대로
g.add_node("assemble_export", assemble_export)  # 그대로
```
